# ─────────────────────────────────────────────────────────────────────────────
# duckdb_mcp_server.py — Windows "서빙 전용" 의존성 (2026-07-27)
#
# 범위: MCP 서버가 stdio로 뜨고, DuckDB 도구 4종 + RAG 도구 6종이 도는 데
#       필요한 것만. 인덱스 빌드·임베딩 대량 생성·수집·분류는 **제외**
#       (그 작업들은 WSL에서만 한다 — SETUP_WINDOWS.md §9 참조).
#
# 산정 근거: 서빙 경로를 실제로 import 해서 얻은 목록.
#   duckdb_mcp_server.py
#     → mcp.server.fastmcp, duckdb, bm25s
#     → rag_assembly/api.py → search.py → {bm25, embedder, reranker, vectordb}.py
#     → rag_assembly/config.py 가 저장소 루트 config.py 를 exec (→ dotenv)
#     → 질의 시점: embedder → torch + sentence_transformers
#
# 설치 순서 (순서가 중요하다):
#   1) torch 를 **먼저** CUDA 인덱스에서 설치.  아래 [torch] 절 참조.
#      이 파일을 먼저 돌리면 sentence-transformers 가 PyPI의 **CPU 전용** torch를
#      끌어와 GPU를 못 쓴다.
#   2) pip install -r requirements-serving.txt
#      (torch==2.12.0 은 이미 설치된 2.12.0+cu130 으로 충족된다 — PEP 440에서
#       local version `+cu130` 은 `==2.12.0` 을 만족한다. 재설치되지 않는다.)
#
# Python 버전:
#   권장 3.12 (WSL 정본과 동일: 3.12.3). 3.11 / 3.13 도 가능.
#   ⚠ 3.14 는 쓰지 말 것 — numpy 2.2.6 에 cp314 win_amd64 휠이 없어
#     소스 빌드로 떨어진다(실측: PyPI 파일 목록 cp310~cp313 + py3).
#   ⚠ 다른 앱의 venv 안에 있는 Python 을 재사용하지 말 것. 전용 venv 신설.
#
# 버전 고정 정책:
#   WSL 정본 venv에서 실제로 도는 버전을 == 로 못박았다. 인덱스(LanceDB 포맷,
#   bm25s 파일 포맷, pickle protocol 5)를 읽는 쪽이라 판 버전이 어긋나면
#   조용히 깨질 수 있는 자리다. 올릴 때는 WSL 쪽을 먼저 올리고 재검증할 것.
# ─────────────────────────────────────────────────────────────────────────────

# ── [torch] GPU 휠 — 이 파일 실행 **전에** 별도로 설치 ──────────────────────
# RTX 4060 (sm_89) / CUDA 13.0 빌드, WSL 정본과 동일:
#
#   pip install torch==2.12.0 --index-url https://download.pytorch.org/whl/cu130
#
#   (검증 2026-07-27: download.pytorch.org/whl/cu130 에 torch-2.12.0 의
#    win_amd64 cp310/cp311/cp312/cp313/cp314 휠 존재)
#
# GPU 없이/드라이버 문제로 CPU만 쓸 경우:
#
#   pip install torch==2.12.0 --index-url https://download.pytorch.org/whl/cpu
#
#   CPU 폴백은 코드에 이미 있다 (embedder.py::load_model — CUDA 로드 실패 시
#   자동 CPU 재시도). 질의 1건 임베딩이 GPU 대비 수 배 느려질 뿐 결과는 같다.
#   강제하려면 env RAG_EMBED_DEVICE=cpu.
